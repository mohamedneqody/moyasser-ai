## 2. تفاصيل الحل المقترح (جاهزة للنسخ مباشرةً في نموذج التقديم)
**«مُيسّر الضرائب الذكي — Moyasser AI v2.5»** هو منظومة ذكاء اصطناعي سيادية هجينة (**Sovereign Neuro-Symbolic AI**) صُمّمت خصيصاً لتلبية **كافة متطلبات كراسة شروط تحدي `TAX-02` بنسبة 100%**، وتدمج بين **أشعة فهم العامية المصرية (`PyTorch BiGRU`)** و**نماذج لغوية محلية أوفلاين (`Ollama Qwen-Hybrid & Liquid LFM-Q4`)** مع **محرك تحسين رياضي (`SciPy HiGHS MILP`)** و**نواة إثبات صوري (`Lean 4.36.0`)** تقضي تماماً على الهلوسة الرقمية والتشريعية.

### مسارا الاستفادة المعتمدان في الحل:
1. **المسار الخارجي (للممولين المصريين والمستثمرين الأجانب — 24/7):**
   - يستقبل الأسئلة بلغة طبيعية (**العربية العامية** للمواطنين ويجيب بـ **فصحى مبسطة**، و**اللغة الإنجليزية** لخدمة المستثمرين الأجانب) عبر **النص، الإملاء الصوتي المباشر، أو رفع ملفات PDF/نصية/ممسوحة ضوئياً**.
   - يوضح التيسيرات المتاحة، وشروط الاستفادة، والمستندات المطلوبة، و**تاريخ سريان كل قانون وينبّه تلقائياً إذا انتهت المهلة أو اقتربت من الانتهاء** (مثل انتهاء مهلة الإقرارات القديمة لقانون 5/2025 في `2025-08-12` مقابل سريان قانون إنهاء المنازعات 152/2026 حتى `2026-12-31` وسريان قانون 6/2025 بصفة دائمة).
   - يقترح **3 أسئلة سياقية ذكية** بعد كل إجابة، ويعتذر بوضوح عن الأسئلة خارج النطاق مع **إحالتها آلياً لموظف خدمات المستثمرين مرفقةً بملخص منقّى للمحادثة (`ETA-ESC-...`)**.
2. **المسار الداخلي (أداة مساندة لموظفي الإدارة العامة لخدمات المستثمرين ومصلحة الضرائب):**
   - بحث تشريعي دلالي فوري أثناء المقابلات الشخصية داخل **18 وثيقة وقانون رسمي فعلي محمّل من `eta.gov.eg` و`media.mof.gov.eg` (437 فقرة موثقة بـ SHA-256)**.
   - **تحديث فوري للقرارات والكتب الدورية الجديدة دون إعادة بناء الحل (`Zero-Rebuild Hot-Reload`)** في أقل من ثانية.
   - طابور متابعة التذاكر المحالة وملخصات المحادثات + **لوحة متابعة مبسطة بأكثر الأسئلة تكراراً (`Top Frequent Questions`)**.

## 3. مصفوفة التطابق الكامل مع شروط تحدي `TAX-02` ومعايير تقييم `SECC`

| متطلب كراسة شروط `TAX-02` الرسمية | التنفيذ الفعلي الموثّق في `Moyasser AI v2.0` |
|---|---|
| دعم العامية المصرية + الإنجليزية للمستثمرين الأجانب | كشف تلقائي للغة (`AR / EN`) وإجابة بالفصحى المبسطة أو الإنجليزية الاحترافية |
| الالتزام بالمصادر الرسمية وذكر المرجع وتاريخ السريان والمهلة | 18 ملف PDF رسمي (القوانين 5–7/2025 و148–153/2026) + فحص آلي للمهل المنقضية والسارية |
| تنويه صريح بأن الإجابات استرشادية وليست فتوى ملزمة | تنويه قانوني ثابت بالعربية والإنجليزية في كل رد وتقرير HTML/PDF |
| الاعتذار عن غير المغطى والإحالة لموظف مع ملخص المحادثة | كاشف نطاق آلي ينشئ تذكرة `ETA-ESC-...` مع ملخص المحادثة لطابور الموظفين |
| تحديث المحتوى بقرارات جديدة دون إعادة بناء الحل | نقطة ربط وشاشة `POST /api/knowledge/ingest-decree` تفهرس القرار في الذاكرة فوراً |
| استقبال نص + مقطع صوتي + ملف نصي أو ممسوح ضوئياً | دعم النص + الإملاء الصوتي `Web Speech` / `/api/voice-query` + رفع PDF (`pypdfium2`) وصور |
| اقتراح 3 أسئلة للمستخدم بعد كل إجابة حسب السياق | حقل `suggested_followups` يعرض 3 أزرار تفاعلية مخصصة لكل مسار ولغة |
| عدم طلب أو معالجة الرقم القومي أو التسجيل (قانون 151/2020) | درع حجب استباقي للبيانات الشخصية قبل أي تحليل أو تخزين أو إحالة |
| لوحة متابعة مبسطة بأكثر الأسئلة تكراراً | جدول `frequent_questions` حي يعرض أكثر استفسارات الممولين تكراراً |
| **الإضافة الفارقة للابتكار (25%–30% من الدرجة)** | **أشعة فهم العامية (`PyTorch BiGRU`) + مستشار سيادي أوفلاين (`Ollama Qwen-Hybrid & Liquid LFM`) + محرك `SciPy HiGHS MILP` + نواة إثبات `Lean 4.36.0` (10 نظريات، `0 sorry`) + 7 موديلات AI مدرّبة + بوابة `X-ETA-Officer-Key` + ختم أمان `CyberGuard SECC` (0 ثغرات)** |

## 4. خطة التنفيذ والاستدامة والتكامل مع أنظمة المصلحة (Implementation Roadmap)
1. **المرحلة الأولى (مكتملة 100% الآن):** نموذج أولي متكامل يعمل بالكامل محلياً أو عبر `Docker`، يشمل المسارين الخارجي والداخلي، ونواة `Lean 4`، والـ 18 تشريعاً رسمياً، وفحص الأمان السيبراني.
2. **المرحلة الثانية (10 يناير – 4 فبراير 2027):** دمج «دليل الدعم الفني الخاص بالتيسيرات الضريبية» فور إتاحته من الوزارة عبر خاصية `Hot-Reload` دون إعادة بناء، وتوسيع اختبارات الأداء الصوتي والمستندات الممسوحة ضوئياً على بيئة `GPU / LLM as a Service` المقدمة من إيتيدا.
3. **المرحلة الثالثة وما بعد المسابقة (مارس 2027):** التكامل المباشر عبر واجهات `REST APIs` الجاهزة مع البوابة الإلكترونية لمصلحة الضرائب (`eta.gov.eg`) ونظام إدارة علاقات المتعاملين بمركز الاتصال ووحدة الرأي المسبق.
